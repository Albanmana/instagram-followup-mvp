# CSV Batch Send Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add CSV drag-and-drop to the extension popup so each `handle,message` row is sent as an Instagram DM with a fixed 400-second gap, running in the background service worker so the popup can be closed without stopping the queue.

**Architecture:** The popup parses the CSV and posts a `START_BATCH` message to `background.js`, which saves the queue in `chrome.storage.local` and processes one row at a time using `chrome.alarms`. Each alarm fires 400 seconds after the previous send. The popup can reconnect at any time and read progress from storage.

**Tech Stack:** Chrome Extension Manifest V3, `chrome.alarms`, `chrome.storage.local`, `chrome.scripting`, vanilla JS (no external libraries)

## Global Constraints

- Alarm name: `"IG_BATCH_NEXT"` — exact string, never vary it
- Delay between sends: `delayInMinutes: 400 / 60` (≈ 6.667 minutes)
- Error policy: skip and continue — log the error, always schedule the next alarm
- CSV format: `handle,message` (comma-delimited, optional header row)
- Storage keys (exact casing): `batchQueue`, `batchIndex`, `batchStatus`, `batchLogs`
- `batchStatus` values: `"running"` | `"done"` | `"stopped"` | `null`
- `batchLogs` capped at 500 entries (same pattern as existing `runLogs`)
- No new dependencies — vanilla JS only

**Files:**

- [ ] **Step 1: Append `scheduleBatchAlarm`**

  ```js
  }
  ```

- [ ] **Step 2: Append `processBatchItem`**

  ```js
  async function processBatchItem(index) {
    const { batchQueue, batchStatus } = await getBatchState();

    if (batchStatus !== "running") return;
    if (index >= batchQueue.length) {
      await setBatchStatus("done");
      return;
    }

    const { handle, message } = batchQueue[index];

    try {
      await sendTestMessage({ handle, message });
      await appendBatchLog({ handle, status: "sent", at: new Date().toISOString() });
    } catch (error) {
      await appendBatchLog({
        handle,
        status: "error",
        error: error.message,
        at: new Date().toISOString()
      });
    }

    const nextIndex = index + 1;
    await chrome.storage.local.set({ batchIndex: nextIndex });

    if (nextIndex < batchQueue.length) {
      scheduleBatchAlarm();
    } else {
      await setBatchStatus("done");
    }
  }
  ```

- [ ] **Step 3: Append the alarm listener**

  ```js
  chrome.alarms.onAlarm.addListener(async (alarm) => {
    if (alarm.name !== "IG_BATCH_NEXT") return;
    const { batchIndex } = await getBatchState();
    await processBatchItem(batchIndex);
  });
  ```

### Task 4: `START_BATCH`, `STOP_BATCH`, `GET_BATCH_STATUS` message handlers

**Files:**
- Modify: `extension/background.js` — add a third `chrome.runtime.onMessage.addListener` block (do not touch the two existing ones)

**Interfaces:**
- Consumes: `getBatchState()`, `clearBatchState()`, `setBatchStatus()`, `processBatchItem()`, `scheduleBatchAlarm()` (Tasks 2–3)
- Produces:
  - `"START_BATCH"` handler — payload `{ rows: Array<{handle, message}> }` — response `{ ok: boolean, error?: string }`
  - `"STOP_BATCH"` handler — no payload — response `{ ok: boolean }`
  - `"GET_BATCH_STATUS"` handler — no payload — response `{ ok: boolean, batchQueue, batchIndex, batchStatus, batchLogs }`

- [ ] **Step 1: Append a new listener block to `background.js`**

  ```js
  chrome.runtime.onMessage.addListener((message, _sender, sendResponse) => {
    if (message?.type === "START_BATCH") {
      (async () => {
        try {
          const rows = message.payload?.rows ?? [];
          await chrome.alarms.clear("IG_BATCH_NEXT");
          await chrome.storage.local.set({
            batchQueue: rows,
            batchIndex: 0,
            batchStatus: "running",
            batchLogs: []
          });
          sendResponse({ ok: true });
          await processBatchItem(0);
        } catch (error) {
          sendResponse({ ok: false, error: error.message });
        }
      })();
      return true;
    }

    if (message?.type === "STOP_BATCH") {
      (async () => {
        try {
          await chrome.alarms.clear("IG_BATCH_NEXT");
          await setBatchStatus("stopped");
          sendResponse({ ok: true });
        } catch (error) {
          sendResponse({ ok: false, error: error.message });
        }
      })();
      return true;
    }

    if (message?.type === "GET_BATCH_STATUS") {
      getBatchState()
        .then((state) => sendResponse({ ok: true, ...state }))
        .catch((error) => sendResponse({ ok: false, error: error.message }));
      return true;
    }

    return false;
  });
  ```

### Task 6: popup.js — `parseCSV`

**Files:**
- Modify: `extension/popup.js` — prepend before existing code

**Interfaces:**
- Produces: `parseCSV(text: string): Array<{ handle: string, message: string }>`
  - Handles double-quoted fields (RFC 4180 subset)
  - Strips leading `@` from handles
  - Trims whitespace from all cells
  - Skips rows where handle or message is empty after trimming
  - Skips header row if first cell (lowercased) is `"handle"` or `"username"`

- [ ] **Step 1: Add `parseCSV` at the very top of `popup.js`**

  ```js
  function parseCSV(text) {
    const lines = text.split(/\r?\n/).filter((line) => line.trim() !== "");

    const rows = lines.map((line) => {
      const cells = [];
      let current = "";
      let inQuotes = false;

      for (let i = 0; i < line.length; i++) {
        const ch = line[i];
        if (ch === '"') {
          inQuotes = !inQuotes;
        } else if (ch === "," && !inQuotes) {
          cells.push(current.trim());
          current = "";
        } else {
          current += ch;
        }
      }
      cells.push(current.trim());
      return cells;
    });

    let start = 0;
    if (rows.length > 0) {
      const firstCell = (rows[0][0] ?? "").toLowerCase();
      if (firstCell === "handle" || firstCell === "username") {
        start = 1;
      }
    }

    return rows.slice(start).reduce((acc, cells) => {
      const handle = (cells[0] ?? "").replace(/^@+/, "").trim();
      const message = (cells[1] ?? "").trim();
      if (handle && message) acc.push({ handle, message });
      return acc;
    }, []);
  }
  ```

  ```js
  function renderBatchProgress({ batchQueue, batchStatus, batchLogs }) {
    const total = batchQueue.length;
    const processed = batchLogs.length;

    batchProgress.hidden = total === 0;
    batchSummary.textContent = `${processed} / ${total} traités — statut : ${batchStatus ?? "—"}`;

    batchLogBody.innerHTML = "";
    for (const entry of batchLogs) {
      const tr = document.createElement("tr");
      const cell = entry.status === "sent"
        ? `<span class="status-sent">✓ envoyé</span>`
        : `<span class="status-error">✗ erreur : ${entry.error ?? "?"}</span>`;
      tr.innerHTML = `<td>@${entry.handle}</td><td>${cell}</td>`;
      batchLogBody.appendChild(tr);
    }

    stopBatchButton.disabled = batchStatus !== "running";
    submitButton.disabled = batchStatus === "running";
  }
  ```

- [ ] **Step 6: Add `handleCSVFile`**

  ```js
  let parsedRows = [];

  function handleCSVFile(file) {
    const reader = new FileReader();
    reader.onload = (e) => {
      parsedRows = parseCSV(e.target.result);
      csvPreview.hidden = false;
      if (parsedRows.length === 0) {
        csvPreview.textContent = "Aucune ligne valide trouvée.";
        startBatchButton.disabled = true;
        return;
      }
      csvPreview.textContent = `${parsedRows.length} ligne(s) prête(s) à envoyer.`;
      startBatchButton.disabled = false;
    };
    reader.readAsText(file);
  }
  ```
